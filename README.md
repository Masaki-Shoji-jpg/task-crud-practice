# task-crud-practice

## 概要
COACHTECH 教材 Tutorial 11-2「タスク管理APIのCRUD実装」で作成した成果物です。
APIResourcesの学習の為Postmanを使用してデータを参照・更新・削除する機能を作成しました。

## 使用技術
- PHP 8.3
- Laravel 10.x
- REST API（CRUD）
- API Resources、FormRequest（バリデーション）

## 学んだこと
- HTTPステータスコードの使い分けを学習しました。
- API Resourcesによる整形方法を学習しました。

## 動作確認
Postmanにより基本データの参照や新たなデータの追加・削除ができるかどうか。
